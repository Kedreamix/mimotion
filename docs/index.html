怎么设置这个密码？

不要写进 GitHub 参数或这个网页。密码放在 Cloudflare Worker 密钥里。

  1. 在仓库根目录执行 npx wrangler deploy
  2. npx wrangler secret put OWNER_PASSWORD（你自己定的看板密码）
  3. npx wrangler secret put OWNER_USER 和 OWNER_PWD（Zepp Life 账号）
