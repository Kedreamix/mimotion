ABOUT

关于迈步

工具说明与使用方法。迈步通过 API 把你指定的步数交给华米，用来更新 Zepp Life 里今天的步数。

功能介绍

输入自己的账号、密码和目标步数，由 Worker 直连华米登录并上传。不定时、不入库，走完这一趟就结束。

使用方法

  1. 输入注册 Zepp Life 时用的邮箱或手机号
  2. 用手打该账号的密码，不要用浏览器自动填充。密码不对大约 1–2 秒就会返回，等回执即可
  3. 点快捷档或「随机」，不用拉滑块；也可以自己填 1 – 98,800
  4. 点「走这一趟」。出现「这一趟到了」才算成功
  5. 打开 Zepp Life 下拉刷新核对

服务指标

接口版本 API v1.0。顶部成功率 99.9%，中位耗时按 ≤2s 展示。

华米登录 + 换票 + 上传通常很快；密码不对等回执即可，大约 1–2 秒。

同一网络请别连点，接口有短时限流。

注意事项

  • 仅供学习、测试，请只动自己的号
  • 不要把步数拉得太离谱，以免被判定异常
  • 账号密码只用于这一次请求，页面和 Worker 都不保存
  • 要用 Zepp Life 密码，不是小米账号快捷登录，也不是看板站长密码
