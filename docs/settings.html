OWNER PASSWORD

站长密码怎么设

Cloudflare Secret
不要写成 GitHub 参数

不要写到仓库 Variables、params.json 或这个页面。公开仓库里谁都能看到。密码只放 Cloudflare Worker 的 Secret。

  1. 部署 Worker

    在仓库根目录执行 npx wrangler login，再执行 npx wrangler deploy。

  2. 添加三个密钥

    打开 Cloudflare 控制台 → Workers & Pages → mimotion → Settings → Variables and Secrets，添加：

    • OWNER_PASSWORD — 看板上输入的站长密码，你自己定
    • OWNER_USER — 你的 Zepp Life 账号
    • OWNER_PWD — 你的 Zepp Life 密码

    命令行也可以：npx wrangler secret put OWNER_PASSWORD，另外两个同理。

  3. 回看板刷步

    打开看板，输入刚才设的 OWNER_PASSWORD，点马上刷步。不用 GitHub PAT。
